# 02｜会话与运行时

## Manager 启动路径（main()）

`python3 channel/manager.py [--serve|--test "文本"]`
- 无参数 / `--serve`：常驻。`load_config` → `ChannelManager(cfg)` → `run()`：
  `load_adapters()`（逐个 attach，单个失败仅跳过不拖垮）→ 打印就绪 → 信号安装 → 阻塞。
- `--test "文本"`：加载适配器 → 以 `local` 平台注入一条消息 → 等会话日志稳定（连续 3s 无增长）
  或超时 min(task_timeout, 180s) → 杀任务 → 打印 `outbox-local.log` 尾部。**无真 IM 时的验收入口**。

## 配置加载（load_config）

- 顺序：`DEFAULT_CONFIG` ← `config.json`（存在则覆盖，浅合并）。
- 路径：`channel/config.json`；可用环境变量 `CHANNEL_CONFIG` 指到别处。
- 常见坑：写临时配置文件后**先验证存在**再跑；文件不存在会静默回落默认值（可能意外跑别的 agent）。

## 运行时目录布局

`runtime_dir` 默认 `/tmp/agent-channel`（重启即清，不落持久状态）：

```
/tmp/agent-channel/
  inbox/            # 旧版字段兼容（实际已按会话放 runtime/.../inbox）
  runtime/
    sess_<sid>/
      api.sock      # TaskSocket，0600
      agent.out     # Agent stdout 日志
      inbox/<seq>/  # 每轮附件
  channel.pid        # control.py 写的 PID（含 --serve 时）
  channel.state.json # control.py 写运行态元数据
  channel.log        # manager 日志（control 侧）
  outbox-local.log   # local 适配器回复落盘
```

## 登录态（持久化，勿入库）

- 微信：`~/.local/share/agent-terminal/channel/ilink-weixin/accounts/`（accounts.json 索引 +
  `<accountId>.json`，0600；含 token）→ 重启免重扫。
- QQ：由 qqdeploy.py 管理 NapCat，登录态在 NapCat 数据目录
  `~/.local/share/agent-terminal/qq/`；QQ 消息通道本身无 token（走本机 OneBot）。
- 上述目录属于运行环境、不在仓库内；.gitignore 对可能产生的副本也有双保险。

## 进程清理语义

- `/new` → `_drop_session`：置 dying → killpg SIGKILL → 关 socket → rmtree `rt/`。
- Manager 退出（Ctrl-C/SIGTERM/SIGINT）→ `_kill_all_tasks` 清杀全部会话子进程，防孤儿。
- 会话子进程崩溃（rc!=0 非 /new）→ drain 线程结束 → 回传错误告知，请用户 `/new` 重开。
- `_drain` 读到 EOF 才收尾：**子进程必须能自然退出**（stdin 关闭或主动 exit），
  否则会话残留。清理统一用 python `shutil.rmtree`/`os.remove`（本项目的运维纪律）。

## 并发与锁

- `tlock`：RLock 保护 `sessions` dict（spawn/摘除原子性）。
- `wlock`（每会话）：写 stdin 串行化——同会话消息按到达顺序投喂。
- 每条消息处理在**独立线程**（`on_message` → `_deliver`），长任务不阻塞收消息。
- 跨会话无共享状态 → 无需全局队列。
