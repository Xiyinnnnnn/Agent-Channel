# 05｜配置参考

配置文件：`channel/config.json`（不存在时全用默认；`cp config.example.json channel/config.json` 起步）。
整体配置 dict 由 `DEFAULT_CONFIG` 与文件浅合并。

## 字段总表

| 字段 | 默认 | 说明 |
|---|---|---|
| `agent` | `"./agents/demo_agent.py"` | Agent 程序。相对路径以**仓库根**为基准；可绝对路径。指向任意满足 03 协议的程序 |
| `multimodal` | `true` | true：图片标 `[图片]` 其余标 `[附件]`；false：一律 `[附件]`（无视觉 Agent 用） |
| `runtime_dir` | `"/tmp/agent-channel"` | 运行期目录（会话 runtime/附件/日志）。重启可清 |
| `allowed_file_dirs` | `["<runtime_dir>", "<仓库根>"]` | `channel-send-file` 白名单；配置里写会**整体替换**默认值 |
| `task_timeout` | `1200` | 单任务超时上限秒（--test 实际限 min(此值,180)） |
| `max_file_mb` | `200` | 出方向文件大小上限 |
| `exit_grace` | `3` | 任务结束清理等待秒（预留） |
| `adapters` | `["local"]` | 启用适配器名单，可选 `local`/`qq`/`wechat` |
| `wechat` | `{}` | 微信配置（见下） |
| `qq` | `{}` | QQ 配置（见下） |

## agent 写法

```jsonc
// ① 仓库内脚本（相对仓库根）
"agent": "./agents/demo_agent.py"
// ② 任意绝对路径的 Agent（如 Agent-in-Terminal 的 term_agent.py）
"agent": "/opt/Agent-in-Terminal/term_agent.py"
// ③ 转发壳（把任务转发到你自己的端口/远程 Agent，见 03 节示例 forwarder.py）
"agent": "/path/forwarder.py"
```

## qq 段（config.json 里 `"qq": { ... }`）

```jsonc
"qq": {
  "bot_qq": "123456",              // 机器人 QQ 号（群@识别用）
  "onebot_http": "http://127.0.0.1:3000",  // OneBot 正向 API 地址（发消息）
  "webhook_local": "127.0.0.1:18086",      // 本机反向HTTP接收（NapCat 往这推事件）
  "webhook_path": "/onebot"                // 反向事件路径
}
```
- 全默认时：`bot_qq` 空 → 群消息按「任意 @」宽松触发；`onebot_http` 空 → 发送时报错明确提示。
- 不想手搓 NapCat：用控制中心菜单 3（qqdeploy 自动部署+扫码）。

## wechat 段

```jsonc
"wechat": { "accounts": [] }   // 显式账号列表；留空 = 自动用已持久化登录态
```
- 真正接入前必须在控制中心执行一次「微信登录」（二维码）；token 存 HOME 目录，不入配置。

## 多模态开关怎么持久化

control.py 菜单 4 会直接改写 `channel/config.json` 的 `multimodal` 字段（0600）。
只影响**新任务**（每条任务文本构造时读取）。
