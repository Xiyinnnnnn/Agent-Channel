# 04｜适配器开发（新增一个 IM 平台）

## BaseAdapter 契约（adapters/base.py）

```python
class BaseAdapter:
    name = "base"
    def __init__(self, cfg): self.cfg = cfg          # cfg 是整体配置 dict
    def attach(self, manager):                        # manager 调它：注册+开始接收
        self.manager = manager; self.start()
    def start(self): raise NotImplementedError        # 起接收循环/HTTP服务
    def stop(self): pass
    def receive(self, msg): self.manager.on_message(msg)  # 归一化后回调给核心
    def send_text(self, msg, text): raise NotImplementedError
    def send_file(self, msg, path): raise NotImplementedError
```

新平台要做的事，就 4 件：
1. 继承 BaseAdapter，实现 `start`/`send_text`（`send_file` 按平台能力，实现不了就抛明确错误）。
2. 把平台收件归一成 **Message dict**（字段见 01 节），调 `self.receive(msg)`。
3. 回复：`send_text` 用 `msg["conversation_id"]`+`msg["sender_id"]` 决定发到哪个会话/人。
4. 在 `adapters/__init__.py` 的 `create_adapters(cfg)` 里注册（工厂返回 name→adapter dict，
   manager 按 `cfg["adapters"]` 名单过滤启用）。

**纪律：适配器只做平台通信，绝不掺 Agent 逻辑；异常绝不能把整个 manager 拖死**
（manager.load_adapters 对单个适配器 start 失败只告警跳过）。

## 既有适配器解剖

### local（测试桩）
- 收：`--test` 注入。发：`send_text/send_file` 写入 `/tmp/agent-channel/outbox-local.log` 并打印。
- 永远启用（`create_adapters` 固定带它），用于无 IM 时的全链路验证。

### qq（OneBot11 / NapCat / Lagrange）
- 收：内置 `ThreadingHTTPServer` 收「反向 HTTP」事件，默认 `127.0.0.1:18086/onebot`。
  - body 读取兼容 **Content-Length 与 chunked 两种编码**（NapCat 真实上报无 CL，只读 CL 会静默丢事件）。
  - 先回 200 再异步处理（防平台重试堆积）。
  - `allow_reuse_address = True`：端口 TIME_WAIT 残留可立即重绑（防连带微信一起起不来）。
- 事件筛选：`post_type=="message"`；私聊直接触发；群聊**必须 @bot**（双形式识别：
  segment 形式 `{"type":"at","data":{"qq":bot}}` 与 CQ 字符串 `[CQ:at,qq=bot]` 兜底）；
  传给 Agent 的正文会去掉 @。
- 附件：CQ `image` 段的 url → attachments（URL 列表）。
- 发：`POST {api}/send_private_msg` / `send_group_msg`（按 conversation_id 前缀 group: 区分），
  超时 20s。`onebot_http` 未配置时明确报错。

### wechat（iLink 逆向）
- 收：每账号 `getUpdates` 长轮询（35s）；上下文记忆按 `context_token`（官方 userId 最新语义）。
- 消息过滤：`message_type==2`（自己发的 echo）跳过；无 from 跳过。
- 附件：媒体消息不自动下载（自研通道无 key 解密）→ attachments 放一行中文摘要提示。
- 发：`sendmessage`（带 context_token）；多账号时用 msg["account_id"] 路由，未标注且唯一则自动用。
- 发文件：**未实现**（CDN+AES），抛明确错误提示 Agent 用文字/链接。
- 登录态：`ilink/accounts.py` 持久化到 HOME（重启免重扫）；登录流程在 control 菜单执行。

## 新增平台清单（照抄步骤）

1. `adapters/xxx.py`：写 `class XxxAdapter(BaseAdapter)`。
2. `__init__.py` 注册：`ads["xxx"] = XxxAdapter(cfg)`。
3. `config.example.json` 加一段说明（文档 05 的配置表同步）。
4. 自测：先用 local 语义验证归一化（把收到的消息打印成 Message），再用桩服务器模拟平台回包。
